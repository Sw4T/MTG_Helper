# MTG_Helper
Fichiers PHP/HTML/SQL d'aide pour le MTG_Project by Polo®

## Install & setup
- Cloner le repo dans le dossier **www** du serveur Apache/WAMP
- Créer la base de données **mtg_project** puis importer le fichier **cartes.sql**
- Définir les droits d'utilisateurs root pour *127.0.0.1* et *localhost* avec le mot de passe suivant : **toor**

**mtg_json_form.html** permet d'ajouter des cartes depuis la base distante vers le local à l'aide de paramètres

**mtg_collection.php** permet de consulter sa collection locale en utilisant de filtres

**mtg_animate.html** est une page sandbox pour tester des animations sur des cartes de la base locale

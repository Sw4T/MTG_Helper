# MTG_Helper
Fichiers PHP/HTML/SQL/JavaScript d'aide pour le MTG_Project by Polo®

## Installation & setup
- Cloner le repo dans le dossier **www** du serveur Apache/WAMP
- Créer la base de données **mtg_project** puis importer le fichier **cartes.sql**
- Définir les droits d'utilisateurs root pour *127.0.0.1* et *localhost* avec le mot de passe suivant : **toor**

## Fichiers à afficher dans le navigateur

**mtg_json_form.html** permet d'ajouter des cartes depuis la base distante vers la base locale à l'aide de paramètres

**mtg_collection.php** permet de consulter sa collection locale en utilisant des filtres

**mtg_animate.html** est une page pour tester des animations avec JavaScript sur des cartes de la base locale
